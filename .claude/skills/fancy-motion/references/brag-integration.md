# How /fancy-motion builds on /brag

/brag (installed at `~/.claude/skills/brag`) makes 15–25 s launch videos with HyperFrames.
/fancy-motion keeps what already works there and adds what a longer, narrated, character-led
film needs. Rule: **share, don't fork.** Assets are read from /brag's own folder at run time
(`fm.mjs brag` prints where); nothing is copied into this skill, so a /brag update reaches both.

## Reused from /brag (in place)

| Capability | Where it lives in /brag | How /fancy-motion uses it |
|---|---|---|
| Renderer: HyperFrames (HTML → MP4, seekable, `check` gate) | `references/step-3-compose.md`, the hyperframes-* skills | Same renderer, pinned (`skill.json → renderer`). Compositions are generated by `scripts/lib/compose.mjs` and pass `hyperframes check`. |
| Voice path: Kokoro-82M via HyperFrames (`npx hyperframes tts`) | `step-3-compose.md` → Voiceover | `scripts/voice.py` loads the **same model files** HyperFrames downloads into `~/.cache/hyperframes/tts/` and adds per-phrase synthesis, a pronunciation lexicon, voice blends and a duration report. |
| CC0 SFX library (Kenney) + keypress set | `assets/sfx/{interface,impact,casino,ui,keyboard}` | `scripts/score.py` reads `keyboard/keypress-*.wav`, `interface/click_003.ogg` (low high-frequency risk per /brag's analysis) and `casino/card-slide-1.ogg` directly. |
| SFX analysis (high-frequency risk) | `assets/sfx/sfx-analysis.md/json` | Guides which /brag files are safe to repeat; repeated UI sounds use the low-risk ones. |
| Music library + cue presets + `analyze_music_cues.py` | `assets/music/`, `scripts/` | Optional: pass a /brag track instead of the synthesized score and use its cue JSON for beat-locks (see audio-and-captions.md). |
| Creative laws: hook first, readable holds (0.8 s label / 0.3 s per word), show the real thing, grounded claims, poster | `SKILL.md`, `step-2-plan.md`, `step-3-compose.md` | Carried into the /fancy-motion laws and checks; the manifest validator enforces the reading floor. |
| Deterministic CDP recorder pattern (virtual clock + scripted real input) | from the DISSECT film made with /brag (`capture/record.mjs`) | WONDER DESK's recorder follows it; documented in render-and-review.md. |
| Original-score engine | from the DISSECT film made with /brag (`audio-src/score.py`) | Generalised into `scripts/score_engine.py` + manifest-driven `scripts/score.py`. |

## New in /fancy-motion

- **Scene manifest** (`manifest.src.mjs` → `manifest.json`): one source for absolute frames,
  narration placement, captions, beats, media windows, camera/transition notes and sound cues;
  `fm.mjs validate` checks coverage, gaps, overlaps and readability.
- **60 fps master spec** with an exact-frame verifier (`fm.mjs verify`).
- **Component vocabulary** (`assets/templates/starter/fm/`): kinetic titles, subtitles, pixel
  wipe, screen surfaces (monitor reveal via homography), floating file, code panel, terminal,
  lower third, iteration compare, end card, voxel builder, particle field, grid stage.
- **Voice measurement loop**: synth → Whisper alignment → blind-WER check → retime from audio.
- **Score + mix engine** driven by the manifest (`"mix"` block): energy-shaped arrangement,
  cue-based sound design, music and effects ducked under the voice, −14 LUFS mastering with codec
  headroom so the delivered AAC stays ≤ −1 dBTP (re-measured and trimmed by `fm.mjs render`).
- **Layering that keeps text readable**: below (screens) · canvas · mid (cards media may cover) ·
  media · above (titles, captions, callouts).
- **Review/refine loop with checkpoints** (`fm.mjs status`): boundary/hold sheets, a per-frame
  motion audit (flicker, frozen runs), effect loudness vs speech (`audio_qa.py cues`), transcript
  WER, and preserved revision evidence.

## Adapting to what /brag offers on a given machine

1. `node ${CLAUDE_SKILL_DIR}/scripts/fm.mjs brag` — if /brag is found, its SFX/music are used
   in place. If not, `score.py` synthesizes every effect and the film still renders.
2. If HyperFrames' Kokoro model is not cached yet, run `npx hyperframes tts "test" -o t.wav`
   once (that is /brag's own voice path) — `voice.py` then finds it.
3. Prefer /brag for a 15–25 s launch brag; use /fancy-motion for narrated, multi-scene films,
   explainers and anything that must prove real interactions over a longer arc.
